# SMAA 0.1 — functional self-modeling

SMAA is a standard-library Python reference subsystem for auditable functional self-modeling in digital-cell networks. It is not a consciousness implementation or a claim of subjective experience.

Run:
- python -m unittest discover -s tests -v
- python -m smaa

See docs/SMAA_ARCHITECTURE.md and docs/SMAA_TEST_PROTOCOL.md for architecture, trust boundaries, staged completion and scientific limitations.
