# SMAA 0.1 test protocol

## Claim under test
The software maintains and revises an explicit, auditable functional model of network identity, membership, capabilities, knowledge provenance, predictions and unknowns.

## Required controls for scientific claims
At equal compute and memory budgets compare: A) event log only; B) fixed/prewritten self-report; C) active self-model that changes action selection; D) deterministic state tracker. Intervene by withholding, corrupting or replacing self-model components. On held-out tasks measure false self-attribution, missed self-actions, identity reconstruction accuracy, Brier score, ECE, revision precision/recall, latency, memory and total compute.

## Current status
The included suite is a deterministic smoke/reference suite with ten unit tests and eight reference probes. It is not a blinded held-out experiment, does not establish causal benefit over controls and does not support a consciousness claim. Future thresholds must be preregistered before outcome inspection.
